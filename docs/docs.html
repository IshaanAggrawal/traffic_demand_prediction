Documentation

Welcome to the detailed documentation for the Traffic Demand Prediction pipeline. Here you'll find everything from data ingestion to the final ensemble code, providing a clear view into our methodology.

Installation

To run this pipeline, you will need the following libraries installed in your Python environment:

pip install lightgbm xgboost catboost optuna pandas numpy scikit-learn scipy

Data Preprocessing

The first step involves parsing the timestamp feature into continuous slot indices to represent 15-minute intervals throughout the day. This creates 96 distinct slots per day.

def parse_slot(ts):
    h, m = ts.split(':')
    return int(h) * 4 + int(m) // 15   # 96 slots per day

for df in [train, test]:
    df['slot'] = df['timestamp'].apply(parse_slot)
    df['hour'] = df['timestamp'].apply(lambda x: int(x.split(':')[0]))

Feature Engineering

The core of the pipeline is a highly optimized feature generation function that calculates hierarchical target encodings. It explicitly uses a source_df to prevent data leakage.

def build_features(target_df, source_df):
    gm  = source_df['demand'].mean()
    
    # Geo+slot target encodings (the most powerful features)
    gsl  = source_df.groupby(['geohash','slot'])['demand'].mean().to_dict()
    gl   = source_df.groupby('geohash')['demand'].mean().to_dict()
    sl   = source_df.groupby('slot')['demand'].mean().to_dict()
    
    d = target_df.copy()
    
    # Primary feature: exact geohash×slot mean (with hierarchical fallback)
    d['geo_slot_te'] = [gsl.get((g,s), gl.get(g, sl.get(s, gm)))
                         for g,s in zip(d['geohash'], d['slot'])]
    
    # Cyclical time features
    d['hour_sin'] = np.sin(2*np.pi*d['hour']/24)
    d['hour_cos'] = np.cos(2*np.pi*d['hour']/24)
    
    return d

Modeling

We train three different gradient boosting trees. Here is the implementation for LightGBM with early stopping based on the Day 49 validation set. The optimal number of iterations is saved for the final retrain.

import lightgbm as lgb

lgb_m = lgb.LGBMRegressor(
    n_estimators=3000, learning_rate=0.02,
    num_leaves=127, min_child_samples=10,
    subsample=0.8, colsample_bytree=0.8,
    reg_alpha=0.05, reg_lambda=0.5,
    random_state=42, verbose=-1
)

Ensemble & Blending

We combine predictions from LightGBM, XGBoost, and CatBoost using an optimal weighted average found via grid search to maximize the R² score on the validation data.

import numpy as np
